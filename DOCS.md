# Документация проекта «Деловая жизнь»

## 1. Общее описание

Сайт бизнес-клуба «Деловая жизнь» — многостраничный статический сайт с адаптивным дизайном, светлой/тёмной темой и интерактивными компонентами.

---

## 2. Архитектура

### 2.1. Файловая структура

```
business-life/
├── index.html              # Главная — hero, миссия, статистика, форматы, преимущества, резиденты, отзывы, новости
├── residents.html          # Резиденты — фильтры, карусель, карточки
├── ecosystem.html          # Экосистема — инструменты, партнёры, CTA

├── js/
│   └── script.js           # Единый файл скриптов (~770 строк)
├── assets/
│   └── images/             # Папка для изображений
├── .gitignore
├── README.md
```

### 2.2. Принципы

- **Статический сайт** — без серверной части, сборщиков и зависимостей
- **Vanilla JS** — никаких фреймворков и библиотек
- **CSS Variables** — единая система дизайн-токенов
- **Mobile-first** — адаптивность от малых экранов к большим

## 3. Стили (css/style.css)

### 3.1. Дизайн-токены

Все стили используют CSS-переменные из `:root`. Для тёмной темы переменные переопределяются через `[data-theme="dark"]`.

**Группы переменных:**
- Цвета: `--bg-main`, `--bg-white`, `--color-accent`, `--color-graphite` и др.
- Тени: `--shadow-sm`, `--shadow-md`, `--shadow-lg`, `--shadow-card`
- Скругления: `--radius-sm` … `--radius-full`
- Отступы: `--space-xs` (4px) … `--space-6xl` (120px)
- Типографика: `--font-size-xs` (11px) … `--font-size-hero` (72px)
- Переходы: `--transition-fast` (0.15s), `--transition-base` (0.3s), `--transition-slow` (0.5s)

### 3.2. Тёмная тема

Активируется атрибутом `data-theme="dark"` на `<html>`. Все переопределения цветов и теней находятся в блоке `[data-theme="dark"] { ... }` (строки ~3837–4267).

### 3.3. Точки останова (Breakpoints)

| Брейкпоинт | Устройство |
|------------|-----------|
| `@media (max-width: 480px)` | Малые мобильные |
| `@media (min-width: 768px)` | Планшеты |
| `@media (min-width: 1024px)` | Десктоп |
| `@media (min-width: 1440px)` | Большие экраны |
| `@media (max-width: 1023px)` | Мобильное меню |

### 3.4. Анимации

- `fadeIn`, `fadeInUp`, `slideInLeft`, `slideInRight`, `scaleIn` — появление элементов
- `float` — плавающие декоративные элементы
- `pulse` — пульсация кнопок
- `gradientShift` — градиентный текст CTA
- `themeRipple` — радиусная смена темы
- `pageLoad` — плавное появление страницы

## 4. Скрипты (js/script.js)

### 4.1. Инициализация

Все функции запускаются в `DOMContentLoaded`:

```javascript
document.addEventListener('DOMContentLoaded', function() {
  initTheme();           // Тема
  initHeaderScroll();    // Sticky-шапка
  initBurgerMenu();      // Бургер-меню
  initSlider();          // Карусель резидентов
  initFilters();         // Фильтры
  initContactForm();     // Форма
  initSmoothScroll();    // Плавная прокрутка
  initCountUp();         // Анимация чисел
  initScrollAnimations();// Анимации при скролле
  initHeroAnimatedBg();  // Анимированный фон hero
  initScrollTop();       // Кнопка «Наверх»
});
```

### 4.2. Переключатель темы (`initTheme`)

1. Читает `localStorage.getItem('theme')`
2. Устанавливает `data-theme` на `<html>`
3. По клику на кнопку:
   - Запускает радиусную анимацию через overlay
   - Меняет тему через 600ms (после анимации)
   - Сохраняет в `localStorage`

**Важно:** Inline-скрипт в `<head>` каждого HTML-файла применяет тему **до** загрузки CSS, предотвращая вспышку светлой темы.

### 4.3. Карусель резидентов (`initSlider`)

- Бесшовная зацикленная карусель: `[клоны конца] [оригиналы] [клоны начала]`
- Адаптивное количество карточек: 1 (моб.) / 2 (планшет) / 3 (десктоп)
- Автопрокрутка каждые 5 секунд (пауза при наведении)
- Свайп-поддержка на мобильных
- Точечная навигация

### 4.4. Фильтры (`initFilters`)

- Работают на страницах резидентов и событий
- Атрибут `data-filter` на кнопках, `data-category` / `data-type` на карточках
- Плавное появление через CSS-анимацию `fadeIn`

### 4.5. Форма обратной связи (`initContactForm`)

- Валидация полей: имя (мин. 2 символа), телефон (10+ цифр), email (формат), сообщение (мин. 10 символов)
- Валидация в реальном времени (на blur и input)
- Имитация отправки с уведомлением об успехе

### 4.6. Анимации при скролле (`initScrollAnimations`)

- `IntersectionObserver` с порогом 0.1
- Каскадная задержка 100ms между элементами
- Применяется к: `.benefits__card`, `.feature-card`, `.resident-card`, `.event-card`, `.format-card`, `.testimonial-card`, `.news-card`, `.about__feature`, `.join__step`

### 4.7. CountUp (`initCountUp`)

- Анимация чисел от 0 до конечного значения
- Easing: `easeOutQuart`
- Длительность: 2 секунды
- Запускается при попадании в область видимости (IntersectionObserver, threshold 0.5)

## 6. Кастомизация

### 6.1. Изменение цветов

Отредактируйте переменные в `:root` (строки 7–96 `css/style.css`):

```css
:root {
  --color-accent: #B89A7A;    /* Основной акцент */
  --color-accent-hover: #A08568; /* Акцент при наведении */
  --bg-main: #F8F6F3;         /* Фон страницы */
  /* ... */
}
```

### 6.2. Добавление страницы

1. Скопируйте существующий HTML-файл
2. Измените `<title>`, контент
3. Добавьте ссылку в навигацию (`<nav class="header__nav">`) всех страниц
4. Добавьте ссылку в футер (`<div class="footer__nav-links">`) всех страниц
5. Добавьте inline-скрипт темы в `<head>`

### 6.3. Добавление изображений

Поместите файлы в `assets/images/` и используйте:

```html
<div class="resident-card__photo">
  <img src="assets/images/photo.jpg" alt="Имя">
</div>
```
