# Деловая жизнь — Бизнес-клуб предпринимателей

Статический сайт премиального бизнес-клуба «Деловая жизнь». HTML, CSS, JavaScript.

### Основные страницы
| Файл | Назначение |
|------|-----------|
| `index.html` | Главная — лендинг с hero, статистикой, форматами, преимуществами, резидентами, отзывами |

## Навигация

**Шапка** (одинакова на всех страницах):
```
[Логотип → Главная]  О клубе | Команда | Резиденты | Блог | Экосистема | События | Контакты  [Гостевой визит]
```

**Хлебные крошки** — полный путь на каждой странице:
- `Главная / Команда / Ирина Южанинова`
- `Главная / Резиденты / IT / Александр Петров`
- `Главная / Блог / Нетворкинг / Как эффективно нетворкить`
- `Главная / События / Форум-группа «Технологии»`

## Функциональность

- Тёмная/светлая тема с радиусной анимацией переключения
- Адаптивный дизайн (мобильное бургер-меню)
- Слайдер резидентов с бесшовной зацикленной прокруткой
- Фильтрация карточек по категориям
- FAQ-аккордеон на странице «О клубе»
- Валидация формы обратной связи
- CountUp-анимация статистики
- Анимации при скролле (IntersectionObserver)
- Кнопка «Наверх»

## Запуск

Открыть `index.html` в браузере или запустить локальный сервер:
```bash
npx serve .
```
