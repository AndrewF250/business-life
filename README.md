# Деловая жизнь — Бизнес-клуб предпринимателей

Премиальное сообщество предпринимателей для нетворкинга, развития бизнеса и обмена опытом.

**Демо**: https://andrewf250.github.io/business-life/

---

## О проекте

Многостраничный сайт бизнес-клуба «Деловая жизнь» — экосистема для предпринимателей, объединяющая нетворкинг, образовательные мероприятия и деловое сотрудничество.

### Страницы

| Страница | Файл | Описание |
|----------|------|----------|
| О клубе | `index.html` | Главная страница — миссия, статистика, форматы мероприятий, преимущества, резиденты, отзывы, новости |
| Резиденты | `residents.html` | Каталог участников клуба с фильтрацией по категориям и каруселью |
| Экосистема | `ecosystem.html` | Инструменты и возможности для роста бизнеса |
| События | `events.html` | Календарь мероприятий — форум-группы, бизнес-завтраки, мастер-классы |
| Контакты | `contacts.html` | Контактная информация, карта и форма обратной связи |

## Функционал

### Тема оформления
- Светлая и тёмная тема с переключением через кнопку в правом нижнем угту
- Тема сохраняется в `localStorage` и применяется при загрузке страницы
- Радиусная анимация при переключении темы

### Навигация
- Sticky-шапка с эффектом прозрачности при скролле
- Адаптивное бургер-меню для мобильных устройств
- Плавная прокрутка по якорным ссылкам

### Компоненты
- **Карусель резидентов** — бесшовная зацикленная карусель с автопрокруткой, свайпами и точечной навигацией
- **Фильтры** — фильтрация карточек по категориям на странице резидентов и событий
- **CountUp анимация** — анимация чисел статистики при попадании в область видимости
- **Анимации при скролле** — каскадное появление карточек через IntersectionObserver
- **Форма обратной связи** — валидация в реальном времени, уведомления об отправке
- **Кнопка «Наверх»** — появляется при прокрутке вниз

### Адаптивность
- Mobile-first подход
- Точки останова: 480px, 768px, 1024px, 1440px

## Быстрый старт

1. Клонируйте репозиторий:
```bash
git clone https://github.com/AndrewF250/business-life.git
```

2. Откройте `index.html` в браузере или запустите локальный сервер:
```bash
# Python
python -m http.server 8000

# Node.js
npx serve .
```

3. Перейдите по адресу `http://localhost:8000`

## Дизайн-токены

Все цвета, отступы, тени и типографика вынесены в CSS-переменные (`:root`), что позволяет легко кастомизировать визуал.

### Основная палитра
| Переменная | Светлая тема | Тёмная тема |
|------------|-------------|-------------|
| `--bg-main` | `#F8F6F3` | `#0D0D0D` |
| `--bg-white` | `#FFFFFF` | `#141414` |
| `--color-accent` | `#B89A7A` | `#C9A96E` |
| `--color-graphite` | `#1E1E1E` | `#FFFFFF` |
